Explain the trade term that matters, then use it accurately.

Source Sans 3 variable carries body text, interface and every chart figure, including large numbers, which use proportional figures; tables use tabular figures. SIL OFL 1.1, self-hosted.

Fallbacks: Iowan Old Style, Palatino, Georgia for display; system-ui for text.

Charts and status

  • mark: primary mark (harbor)
  • mark-range: estimate range, a lighter step of the same ramp; values always also in labels or the table view
  • sea: reserve or secondary context
  • accent: the one emphasized path or series (emphasis form)
  • ink: reference lines such as capacity

Method: thin marks of 24px or less, one baseline, solid hairline grid, legend for two or more series, selective direct labels, a table view for every chart, no dual axes.

Status colors are fixed (good #0CA30C, warning #FAB219, serious #EC835A, critical #D03B3B) and always carry an icon and a label. Work in progress uses harbor, not a status color.

Motif: bathymetry

The masthead's moving contour field draws nautical depth contours in sea glass on ink, with every fifth line as an index contour. It is WebGL2 with a CSS fallback. It renders one static frame for reduced-motion users, pauses offscreen and in background tabs, and caps the pixel ratio for battery. A gradient scrim keeps the wordmark at full contrast. The motif is ready to reuse in a Ghost theme header or a newsletter banner as a rendered still.
