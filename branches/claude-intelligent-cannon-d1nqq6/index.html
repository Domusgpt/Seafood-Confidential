Kit audit · Implementation status · Backlog and critical path

Current session

S01: Repository foundation (turn 1), operations desk foundation and first slice (turn 2), hosting plan and Claude agent lab (turn 3), Ghost-free publishing with agents under policy (turn 4)

Unpacked and audited the launch packet; installed and verified the toolchain; built dev log, delivery tracking, validators, CI and the Pages project hub; researched current vendor facts; wrote the foundation planning brief for the next turn's plan mode. Turn 2 (v0.2.0): built the operations desk foundation (SC-005) and its first vertical slice (SC-006 pitch intake with source and rights records, SC-007 editorial queue with Ghost references, first part of SC-009 agent gateway) on local Supabase, with database policy, unit, end-to-end, accessibility and bundle-secret tests. Turn 3 (v0.3.0): verified hosting and running costs (Supabase Pro plus Cloud Run and Cloud Storage), proposed ADR-004 for automated Ghost drafts with one-click human publishing, added a production container image with a CI smoke test, and built a Claude-powered agent lab whose real runs wait for an API key. Turn 4 (v0.4.0): the founders chose a Ghost-free start (ADR-005). Stories are written in the desk with revisions and published as our own static site (Firebase Hosting; Kit for the newsletter). Agents may publish their own proposals only inside owner switches and database-enforced checks, and people are never blocked. The cost plan drops to about $1 a month to start, with prices verified on official pages. Turn 4, security hardening (v0.4.1): an independent review of agent publishing found one High, four Medium and three Low problems. All are fixed with regression tests: rebuilds use each story's published revision, claim tokens fence every step, the newsletter is sent at most once per job, agent jobs are re-checked when they run, refusals are recorded and budgeted, and agent text is checked as readers see it. Eight more problems found while fixing them are fixed too. Turn 5 (v0.5.0): the desk (Cloud Run, us-west1) and the public site (Firebase Hosting) went live as a preview on Paul's Supabase and Google Cloud projects, with preview banners and noindex everywhere, a hardened sign-in configuration and an owner account for Paul; real-email sign-in and the first publication are the next live checks. Turn 6 (v0.6.0): the preview site now carries seven clearly labelled sample stories (a guarded is_sample flag that only an operator can set, and that the builder refuses on a non-preview site) and About and How we work pages drafted from the founders' copy. The desk gained a publishing sweep endpoint that accepts only a Google-signed token from one service account; the Cloud Scheduler job that would call it is left to Paul. The sample removal path and an owner's update of a live sample were rehearsed locally; a publication by the desk service on Cloud Run is the next live check. Turn 7 (v0.7.0, v0.7.1): the public site gained photographs (six credited public-domain samples; the desk makes AVIF and WebP renditions, strips metadata and pins each image at publish) and a motion and depth system on GSAP ScrollTrigger (layered parallax, reveals that reverse on scroll-back, raised and recessed surfaces lit from one direction), tuned from design tokens v0.2 with presets, a reader switch, reduced-motion and no-JavaScript support. Story images are tied to cleared rights records and agents never publish them (ADR-006, Proposed). Red-teaming the desk's own container with Cloud Run's limits found that a 24-megapixel upload would crash the live desk and that uploads over 10 MB were cut off; v0.7.1 bounds image processing's memory, raises the body limit, names HEIC files, versions the stylesheet's fonts and art, and runs the live desk with 1 GiB (revision sc-desk-00005-dw7). An image upload and a publication by the live desk are the next live checks. Turn 8 (v0.7.2): asked whether images were posted at native size, a live audit showed readers never receive originals and every browser already took the smallest covering rendition; phones denser than 2.5x are now served as if 2x, halving their image bytes (home page 369 to 188 KB) with no visible difference, and the audit became a repository tool (audit:images). Turn 9 (v0.7.3): Dave Simpson got an owner account on the live desk (confirmed identity, principal, owner role, verified under row-level security); he can sign in once Paul invites him to the Supabase organization, because the free mailer emails only organization members and the Management API cannot send invitations. Owners now see in Settings when each staff member last signed in (app.staff_sign_ins(), owners only). Paul's first real-email sign-in was confirmed; a publication by the desk on Cloud Run is still to come.
