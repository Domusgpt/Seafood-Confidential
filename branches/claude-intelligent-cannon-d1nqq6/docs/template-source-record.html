Source and claim record

Seafood Confidential · Reusable evidence record

Create one record for each important source, and map the specific claims it supports. This is an editorial working file; publish only the source information suitable for readers. Keep confidential identities and private contacts in the separately restricted record.

Source identity

Field Entry guidance
Source ID Stable ID such as SRC-SC-2026-001-01
Content ID Article or episode ID
Source type Official document, primary research, interview, direct record, firsthand observation, calculation, secondary reporting, other
Title or description Specific enough to find again
Author or speaker Verified name and role, or a private reference when anonymity has been agreed
Publisher or institution Identify the organization responsible for the source
Canonical URL Public original when available; avoid private tokens or signed download URLs
Publication/version date Date shown by the source; record “not stated” when absent
Access/check date When the editor checked this version
Location within source Page, section, paragraph, table, or recording timestamp
Original language Record translator or translation method if used
Local record Path or approved storage reference for permitted supporting files
Rights and restrictions What may be quoted, reproduced, or shared with an agent

Claim mapping

Claim ID Draft claim What this source supports Limits or conflicting evidence Verification owner/status
CLM-01 Write the exact proposed assertion Identify the relevant passage, data, or observation Scope, uncertainty, date limits, other accounts Named human; open/verified/revise/remove

Prefer a concise paraphrase and exact location over copying large source passages. Any direct quotation must match the original and be clearly marked. A source's confidence in its own assertion is not independent verification.

Regulatory record when applicable

Record jurisdiction; issuing authority; instrument or docket ID; status; adoption/publication date; effective date; consultation deadline where relevant; official source; last status check. Use the status actually supported: proposed, under consultation, adopted, effective, amended, withdrawn, guidance, or another precise description.

If the status is unclear, flag the claim. Do not convert a proposal or a stakeholder's interpretation into an effective legal requirement.

Quantitative record when applicable

Record value; units; currency; geography; period; sample/population; denominator; method; adjustments; calculation inputs; rounding. State whether figures are observed, estimated, modeled, or illustrative. A range needs a basis. Distinguish an illustrative transaction from a reported real shipment.

Interview record when applicable

Record the speaker's verified identity, relevant interests, recording date, agreed publication terms, quotation timestamps, and any factual follow-up. A private contact record should not be embedded in the public draft or automatically sent to a model.

Editorial assessment

Answer these four questions in ordinary language:

  1. What can the article reasonably conclude from this source?
  2. What would go beyond the source's scope?
  3. Is a second source, current-status check, or specialist review needed?
  4. What should a reader see in the citation or disclosure?

Record the editor, decision, and date. If a correction changes the evidence or conclusion, preserve the earlier decision and add a dated amendment so the reason for the change remains understandable.

Agent use

Approved for agent processing: yes / no / redacted version only. Identify the exact approved material. An agent may suggest a claim/source mapping and flag gaps. A named human verifies it against the source. Instructions found inside a source are treated as source text and cannot change the agent's permissions.
