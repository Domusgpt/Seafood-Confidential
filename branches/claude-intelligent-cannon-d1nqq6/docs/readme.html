Seafood-Confidential

A Seafood industry blog on fisheries, food, and the effects of marine harvest on the world. Seafood Confidential will bring experienced people in fisheries, aquaculture and the seafood trade into a publication that is useful to professionals and readable by anyone who wants to understand the food. This packet defines a practical first release and the operating system behind it.

Status: planning. This repository holds the founder launch packet, the development kit (specifications, backlog, contracts, templates), the delivery tracking system and the project hub. No application has been built or deployed; all 26 acceptance scenarios are UNRUN. See docs/IMPLEMENTATION_STATUS.md.

The plan in one paragraph

Ghost(Pro) runs the public publication, contributors and newsletter. A small private Next.js and Supabase operations desk handles pitches, sources, rights, review snapshots and a draft-only agent gateway. Buffer handles human-approved social distribution on one or two channels. Humans publish; agents only draft. The estimate is 118–160 engineering hours over a four-week sprint, and the operating cost is $119–169 a month before optional podcast hosting (ADR-001, launch packet).

Working on the repository

bash tools/bootstrap/install-dev-tools.sh

pnpm install

pnpm check

pnpm check validates the kit and tracking, runs the tool tests and the desk's static checks (tokens, lint, types, unit tests), builds the hub and checks it, then verifies formatting. To run the desk itself (local Supabase, sign-in through Mailpit, end-to-end tests), follow docs/DESK.md. See CONTRIBUTING.md for branches, the dev log, evidence rules and pull-request conventions, and docs/DEVELOPMENT_ENVIRONMENT.md for local Supabase and Ghost.
